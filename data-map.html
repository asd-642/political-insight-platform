Backend Data Map

資料庫紀錄示意

這一頁把大型入口網站常見的後台資料，轉成「政策脈絡」可以採用的資料表設計。它不是 Yahoo 的內部資料，而是你自己的網站未來可接 Firebase、資料庫或分析工具時的紀錄藍圖。

回後台 看目前紀錄

Flow

網站資料怎麼進後台

01 使用者進站

記錄頁面瀏覽、來源頁、裝置基本資訊與同意狀態。

02 互動產生事件

搜尋、點文章、切換分類、留言、檢舉與登入都會形成事件。

03 後台整理資料

資料表把事件歸到會員、文章、廣告版位與審核流程。

04 分析與安全控管

用於熱門內容、廣告成效、異常登入與留言風險判斷。

Local Preview

目前這台瀏覽器已記錄的資料

本區只讀取這台瀏覽器的本機資料，不會把你的帳號或事件送到外部。正式上線後可以改成讀 Firebase 或後端資料庫。

Schema

建議資料表

01

users

會員與管理員帳號。正式站只存密碼雜湊，不存明文密碼。

uid
使用者唯一 ID
email
登入信箱
role
visitor、member、editor、admin
createdAt
註冊時間
lastLoginAt
最近登入時間
privacyConsent
隱私與 Cookie 同意狀態
02

sessions

登入狀態與裝置紀錄，用來判斷是否需要重新登入或提示異常。

sessionId
瀏覽器工作階段 ID
uid
對應使用者
signedInAt
登入時間
device
瀏覽器與系統摘要
ipHash
IP 雜湊值，降低敏感度
expiresAt
過期時間
03

events

網站互動流水帳，是分析熱門內容、搜尋需求與使用路徑的核心資料。

eventId
事件唯一 ID
type
page_view、search、article_select 等
path
發生在哪個頁面
payload
標題、查詢字或文章 ID
uid
可匿名，視隱私設定決定
at
事件時間
04

articles

文章、草稿、來源與審稿狀態，支援你的 AI 草稿審核流程。

id
文章代號
topic
財經、居住、能源等分類
title
標題
status
draft、review、published
sources
來源名稱與網址
updatedAt
更新時間
05

comments

留言、回覆、按讚、檢舉與隱藏狀態，讓後台可以做審核。

id
留言 ID
articleId
留言所屬文章
uid
留言者
body
留言內容
status
visible、hidden、deleted
reportCount
檢舉次數
06

ad_events

廣告版位曝光與點擊紀錄，之後可和 AdSense 或自售廣告報表對照。

impressionId
曝光 ID
slot
728x90、300x250、in-feed
page
出現頁面或文章
campaign
廣告活動，可留空
shownAt
曝光時間
clickedAt
點擊時間，可留空
07

security_logs

登入失敗、異常操作、檢舉高峰與可疑流量，用於風險控管。

id
紀錄 ID
kind
login_failed、spam_report、rate_limit
score
風險分數
reason
觸發原因
status
open、reviewed、ignored
createdAt
建立時間
08

consents

隱私、Cookie、個人化廣告與通知訂閱的同意紀錄。

uid
使用者 ID，可匿名
analytics
是否同意分析
personalizedAds
是否同意個人化廣告
newsletter
是否訂閱通知
version
同意條款版本
updatedAt
最近更新時間
